Speak Clear

講話變簡明

中文：先講結論，再講理由。
English: Answer first. Then explain.

唯一先記這個｜One rule

結論 → 理由 → 例子
Answer → Reason → Example

中文：我建議先延後。 因為資料還沒確認完整。例如，昨天發現兩個數字不一致。

English: I suggest we delay it. The data is not fully confirmed. For example, two numbers did not match yesterday.

我的 5 秒發言框架｜5-second framework

1先回答｜Answer first一句話直接講結論。 / Give the main answer in one sentence.
2再說原因｜Give the reason最多 1–2 個理由。 / Give only 1–2 reasons.
3最後補行動｜Next step需要時才補例子或下一步。 / Add an example or next step only if needed.

英文簡明說話 4 個原則

  • Short sentence. 一句只講一件事。
  • Simple words. 用會的簡單字，不追求艱深單字。
  • Answer first. 不要先鋪陳背景。
  • Stop early. 說完重點就停，不要一直補充。

英文萬用句型｜Useful English

先講結論｜Answer first

My answer is yes.
I think we should...
My suggestion is...
The main issue is...

給理由｜Give a reason

The main reason is...
There are two reasons.
First,... Second,...
This is because...

下一步｜Next step

So, I suggest...
The next step is...
I will finish it by...
We can check it again tomorrow.

三種常用模板｜3 speaking templates

工作回報｜Work update

中文：目前進度正常／目前有一個問題。主要原因是……下一步我會……

English: The progress is on track. / We have one issue. The main reason is... My next step is...

表達意見｜Give an opinion

中文：我的建議是……因為……所以我建議……

English: My suggestion is... The main reason is... So, I think we should...

回答問題｜Answer a question

中文：先回答是／不是／我建議……，再補 1–2 個理由。

English: Yes. / No. / I suggest... There are two reasons. First,... Second,...

不要這樣說｜Avoid this

Too long:
Actually, I think maybe there are several things we need to consider, and yesterday I also checked some information, so maybe we can...

Better:
I suggest we wait one day. We still need to confirm the data.

發言前檢核｜Before I speak

最重要的習慣｜Best habit

先說 70%，停下來。
Say 70%. Then stop.

如果對方需要更多，他會問。
If they need more detail, they will ask.

目標不是講得少，而是讓別人更快抓到重點。
The goal is not to speak less. It is to make your point clear faster.
